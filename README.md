# Stéphane Tsala — Portfolio

Responsive one-page portfolio using plain HTML, CSS and JavaScript. No React and no build step.

## Deploy

### Vercel
Import the GitHub repository, choose **Other**, leave Build Command empty and deploy the project root.

### Render
Create a **Static Site**, connect the repository, leave Build Command empty and set Publish Directory to `.`.

## Customize
- Replace the colored project placeholders in `index.html` with real screenshots later.
- Update project descriptions/links whenever a project gets a live demo.
- Replace `assets/Resume_STEPHANE_TSALA.pdf` if the CV changes.
